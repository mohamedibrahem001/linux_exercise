# Embedded Linux Exercises

This repository contains exercises and examples related to Linux development.

 

## Requirements:
- GCC compiler
- Linux Environment  

  
## Compilation Instructions
To compile the source code, use the following command:

```bash
gcc src_file -o output_file 
```

Replace `src_file.c` with the desired source file name.

## Example Output
After running the compiled program, you might see output like this:

```bash
$ ./pwd
/media/mohamed-ibrahem/Courses/EmbeddedLinux/linux_exercise 
```
